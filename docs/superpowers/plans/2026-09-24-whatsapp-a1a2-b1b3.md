# QRslice WhatsApp A1+A2/B1+B3 Power-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend Baileys WhatsApp to send images/PDFs + buttons/lists, receive inbound, auto-reply to MENU/HELP/TRACK keywords, and provide a staff inbox for human handoff — all via the existing 2-minute cron single pipe.

**Architecture:** Keep `whatsapp-dispatch` cron as sole outbound pipe; extend `whatsapp_messages` with media/buttons payload; wire `BaileysConnectionManager.handleMessagesUpsert` to insert `whatsapp_inbound_messages`, run pure `keyword-router`, enqueue `pending` replies or open `whatsapp_tickets`; inbox UI polls tickets/inbound and replies via existing `POST /api/whatsapp/send`.

**Tech Stack:** Next.js 16 App Router + TypeScript strict, Supabase Postgres + Storage, Baileys `@whiskeysockets/baileys@^7.0.0-rc14`, Vercel cron `*/2 * * * *`, Tailwind 4, Vitest + Testing Library, `qrcode@^1.5.4` (already present)

**Spec:** `docs/superpowers/specs/2026-09-24-whatsapp-a1a2-b1b3-design.md`

```ts
// Copyright (c) 2026 QRslice. All rights reserved.
export interface Button{ id:string; title:string }
export function routeKeyword(body:string, ctx:{restaurantSlug?:string}): {reply:string,buttons?:Button[]}|null{
  const t=(body||"").trim().toUpperCase();
  if(t==="MENU") return {reply:`Hi! Browse menu: https://${ctx.restaurantSlug||"qrslice"}.qrslice.com/menu`, buttons:[{id:"menu",title:"View Menu"}]};
  if(t==="HELP") return {reply:"Need help? Reply SUPPORT or call +91 98765 43210", buttons:[{id:"support",title:"Chat Support"}]};
  const m=t.match(/^TRACK\s+(.+)/); if(m) return {reply:`Order ${m[1].trim()}: checking… (TRACK lookup wired in Task 5)`};
  return null;
}
```

```ts
private async handleMessagesUpsert(tenantId:string, messages:unknown[]){ for(const m of messages as any[]){
  if(m.key?.fromMe) continue; const body=m.message?.conversation||m.message?.extendedTextMessage?.text||m.message?.imageMessage?.caption||""; if(!body) continue;
  const inbound_id=m.key.id; const remoteJid=m.key.remoteJid;
  const {error} = await db.from("whatsapp_inbound_messages").insert({tenant_id:tenantId, remote_jid:remoteJid, push_name:m.pushName, body, raw:m, inbound_id}, {onConflict:"inbound_id"}).select(); if(error && error.code==="23505") continue;
  await db.from("whatsapp_tickets").upsert({tenant_id:tenantId, customer_jid:remoteJid, push_name:m.pushName, last_message_at:new Date().toISOString()}, {onConflict:"tenant_id,customer_jid"});
  const routed=routeKeyword(body, {}); if(routed) await db.from("whatsapp_messages").insert({tenant_id:tenantId, recipient_phone: remoteJid.split("@")[0].split(":")[0], message_type:"keyword_reply", status:"pending", template_variables:{text:routed.reply}, buttons:routed.buttons, inbound_id});
}}
```
